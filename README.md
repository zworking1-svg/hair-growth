# Рост волос — личное приложение для iPhone

**Адрес приложения: https://zworking1-svg.github.io/hair-growth/** — публикуется автоматически при каждом push в `main`.

Приложение для одного человека: схема приёма препаратов и процедур, отметки «принял / пропустил», фото-дневник волос, ИИ-трихолог на базе Claude и аналитика с рейтингом от 1 до 5.

## Почему это веб-приложение, а не «обычное» из App Store

Нативное iOS-приложение без платного аккаунта разработчика собирается только на Mac в Xcode и **перестаёт запускаться через 7 дней** — его приходится переустанавливать каждую неделю. Поэтому здесь сделано веб-приложение (PWA):

- ставится на экран «Домой» и открывается как обычное приложение, во весь экран, с иконкой;
- работает без интернета;
- **все данные (схема, отметки, фото, заключения) хранятся только на вашем iPhone** — никуда не отправляются;
- не нужны App Store, Mac и аккаунт разработчика; всё бесплатно.

## Структура

```
app/                    — само приложение (это и нужно выложить в интернет)
  index.html, styles.css, sw.js, manifest.webmanifest, icons/
  js/app.js             — интерфейс
  js/schedule.js        — расписание, статусы, аналитика, рейтинг
  js/ics.js             — напоминания для Календаря iPhone
  js/report.js          — отчёт для ИИ и разбор его ответа
  js/db.js, images.js   — хранилище и сжатие фото
claude-skill/
  hair-trichologist/SKILL.md   — навык ИИ-трихолога
  hair-trichologist.zip        — он же, для загрузки на claude.ai
```

## Шаг 1. Выложить приложение (бесплатно, один раз)

iPhone должен открыть приложение по адресу `https://…`. Проще всего — GitHub Pages:

1. Зарегистрируйтесь на github.com (бесплатно).
2. Создайте репозиторий, например `hair`, тип **Public** (бесплатный GitHub Pages работает с публичными репозиториями; в коде нет ваших личных данных — они только на телефоне).
3. Загрузите **содержимое папки `app`** (не саму папку) в корень репозитория: *Add file → Upload files*, перетащите файлы и папки `js`, `icons`.
4. *Settings → Pages → Source: Deploy from a branch → main / (root) → Save*.
5. Через 1–2 минуты приложение будет доступно по адресу `https://ВАШ-ЛОГИН.github.io/hair/`.

## Шаг 2. Установить на iPhone

1. Откройте этот адрес в **Safari**.
2. Нажмите «Поделиться» → **«На экран „Домой“»** → «Добавить».
3. Дальше открывайте только с иконки «Волосы» (данные Safari и данные приложения на экране «Домой» — разные хранилища).

## Шаг 3. Заполнить схему и включить напоминания

1. Вкладка **«Схема»** → добавьте всё, что пьёте/наносите: название, дозировку, время (можно несколько), повтор (каждый день / по дням недели / раз в N дней), даты курса, заметку.
2. Нажмите **«Добавить напоминания в Календарь»** → «Добавить все» → лучше выбрать отдельный календарь «Волосы» (создайте его заранее в приложении Календарь).
   iPhone не позволяет веб-приложениям самим ставить будильники без сервера, поэтому напоминания идут через Календарь — они приходят как обычные уведомления, даже когда приложение закрыто.
3. Если меняете схему — удалите календарь «Волосы» (вместе с событиями), создайте заново и снова нажмите кнопку.
   Если кнопка не открывает окно календаря — используйте «Поделиться файлом .ics» → «Сохранить в Файлы» → откройте файл в «Файлах».

Каждый день во вкладке **«Сегодня»** нажимайте ✓ (принял) или ✕ (пропустил). Если отмечаете позже — приложение спросит, во сколько вы на самом деле приняли. Стрелками можно отметить прошлые дни.

## Шаг 4. Подключить ИИ-трихолога (Claude Pro, без доплат)

Важно: подписка Claude Pro **не включает API** — доступ к Claude из стороннего приложения по API оплачивается отдельно. Чтобы оставаться в рамках Pro, приложение не обращается к Claude напрямую, а передаёт фото и отчёт в **приложение Claude** через меню «Поделиться». Анализ идёт внутри вашей подписки.

Настройка один раз:

1. На claude.ai (с компьютера) откройте настройки → раздел навыков (Skills) и загрузите `claude-skill/hair-trichologist.zip`. Включите навык.
2. В Claude создайте проект **«Трихолог»**. Если навыки на вашем тарифе/устройстве недоступны — откройте `SKILL.md`, скопируйте весь текст и вставьте в инструкции проекта. Работает так же.

Каждые 2–4 недели:

1. Сфотографируйте зоны во вкладке **«Фото»** (советы по съёмке — там же).
2. Вкладка **«Трихолог»** → отметьте фото (новые + можно старые той же зоны для сравнения) → **«Поделиться фото и отчётом → Claude»** → выберите Claude, проект «Трихолог», отправьте.
   Если текст не подтянулся — нажмите «Скопировать текст отчёта» и вставьте в чат.
3. Скопируйте ответ Claude → вернитесь в приложение → «Вставить из буфера» → «Сохранить».
   Последняя строка ответа (`HAIRLOG overall=… density=…`) автоматически попадает в график «Динамика по оценкам ИИ».

ИИ не врач. При резком выпадении, очагах облысения, боли, покраснении или зуде — к дерматологу/трихологу.

## Как считается рейтинг

Каждый запланированный приём:

| Статус | Баллы |
|---|---|
| вовремя (±60 мин от плана) | 1 |
| с опозданием | 0,75 |
| пропущено / не отмечено | 0 |

Выполнение = баллы / число приёмов. **5 «Супер»** — от 95%, **4 «Хорошо»** — от 85%, **3 «Средне»** — от 70%, **2 «Слабо»** — от 50%, **1 «Плохо»** — ниже. Приёмы, время которых ещё не наступило, не учитываются. Рейтинг считается за период (7/30/90 дней/всё время), по дням (календарь), по неделям и по каждому препарату.

Если меняете дозировку или время, изменения действуют с сегодняшнего дня — прошлая статистика считается по старой схеме.

## Резервная копия

Данные живут только на телефоне. Раз в пару недель: ⚙︎ → «Резервная копия (с фото)» → «Сохранить в Файлы» (iCloud Drive). Восстановление — там же. Удаление иконки с экрана «Домой» удаляет и все данные.

## Обновление приложения

Измените файлы, загрузите их в репозиторий заново и увеличьте `VERSION` в `sw.js`. Приложение подхватит новую версию при следующем запуске (иногда — со второго).

## Локальный запуск на компьютере

```bash
python -m http.server 8765 --directory app
```

Затем откройте http://localhost:8765.
